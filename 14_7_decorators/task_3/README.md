# logging
Декоратор logging, отвечающий за логирование функций.

На экран выводится название функции и её документация. Если во время выполнения декорируемой функции возникла
ошибка, то в файл function_errors.log записывается название функции, ошибка и ее дата и время возникновения.

Программа не завершается после обнаружения первой же ошибки,
а обрабатывает все декорируемые функции и сразу записывает все ошибки в файл.
