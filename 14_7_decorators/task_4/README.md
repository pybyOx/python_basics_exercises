Декоратор, который кеширует (сохраняет для дальнейшего использования) результаты вызова
функции и, при повторном вызове с теми же аргументами, возвращает сохранённый результат.

В итоге декоратор проверяет аргументы, с которыми вызывается функция, и,
если такие аргументы уже использовались, возвращает сохранённый результат вместо запуска расчёта.

Применен к рекурсивной функции вычисления чисел Фибоначчи.
