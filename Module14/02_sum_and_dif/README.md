## Сумма и разность

**sum_of_digits**

Принимает одно целое положительное число N и находит сумму всех цифр в числе. 

**quantity_of_digits**

Принимает число N и считает количество цифр в числе. 


Выводится разность суммы чисел и количества.

**Пример работы программы:**

```bash
Введите число: 500

Сумма чисел: 5
Количество цифр в числе: 3
Разность суммы и количества цифр: 2
```
