## Словарь синонимов

Программа для оцифровки словарей синонимов. 

На вход в программу подаётся N пар слов. Каждое слово является синонимом к своему парному слову. 

- составляет словарь синонимов (все слова в словаре `различны`)
- запрашивает у пользователя слово и выводит на экран его синоним (если такого слова нет, выводит ошибку и запрашивает слово ещё раз). 
- проверка `не` зависит от регистра символов.

Пример:

```
Введите количество пар слов: 3
Первая пара: Привет — Здравствуйте
Вторая пара: Печально — Грустно
Третья пара: Весело — Радостно

Введите слово: интересно
Такого слова в словаре нет.
Введите слово: здравствуйте
Синоним: Привет
```
