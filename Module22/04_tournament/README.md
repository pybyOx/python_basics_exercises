## Турнир 

В файле `first_tour.txt` записано число K и данные об участниках турнира: фамилии, имена и количество баллов, 
набранных в первом туре. 

Во второй тур проходят участники, которые набрали более K баллов в первом туре. 

Программа выводит в файл `second_tour.txt`:
- в первой строке количество участников второго тура
- затем по убыванию набранных баллов фамилии, инициалы и количество баллов всех участников, прошедших во второй тур, с нумерацией. 

Пример:
```
Содержимое файла first_tour.txt:
80
Ivanov Serg 80
Sergeev Petr 92
Petrov Vasiliy 98
Vasiliev Maxim 78

Содержимое файла second_tour.txt:
2
1) V. Petrov 98
2) P. Sergeev 92
```
