## Файлы и папки

Программа получает на вход путь до каталога (это может быть и просто корень диска) и выводит общее количество файлов 
и подкаталогов в нём. 

Также на экран выводится размер каталога в килобайтах (1 килобайт = 1024 байт).
Для этого находится сумма размеров всех вложенных в него файлов.

Результат работы программы на примере `python_basic\Module14`:
```
E:\PycharmProjects\python_basic\Module14
Размер каталога (в Кб):  9.61
Количество подкаталогов:  3
Количество файлов:  7
```
