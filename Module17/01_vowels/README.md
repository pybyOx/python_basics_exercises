## Гласные буквы

Программа запрашивает у пользователя текст и генерирует список из гласных букв этого текста (сама строка вводится на русском языке). 

Выводит в консоль сам список и его длину.

Пример:

```
Введите текст: Нужно отнести кольцо в Мордор!

Список гласных букв: ['у', 'о', 'о', 'е', 'и', 'о', 'о', 'о', 'о']
Длина списка: 9
```
