## Генерация

Пользователь вводит целое число N. 

Программа генерирует список из чисел от 0 до N (не включая N).

При заполнении списка выполняется одно из двух действий с каждым числом:
- Если индекс числа чётный (или 0), то вместо числа добавляется 1;
- Если индекс числа нечётный, то вместо числа добавляется остаток от деления этого числа на 5 (число % 5).


Реализовано при помощи генератора списка (в одну строку).

Пример:
```
Введите длину списка: 10
Результат: [1, 1, 1, 3, 1, 0, 1, 2, 1, 4]
```
