## Объединение списков

Есть три списка — основной и два побочных. 

Программа объединяет первый побочный с основным, считает и выводит количество цифр 5 в нем, а затем их удаляет. 

После объединяет второй побочный с основным, считает и выводит количество цифр 3. 
В конце также выводится и сам список.

Не использует дополнительные списки.

```
Результат работы программы:
Кол-во цифр 5 при первом объединении: 3
Кол-во цифр 3 при втором объединении: 4
Итоговый список: [1, 3, 1, 1, 1, 3, 1, 5, 3, 3]
```
