## Детали

Дан список названий деталей и их стоимостей:

```python
shop = [['каретка', 1200], ['шатун', 1000], ['седло', 300], ['педаль', 100], ['седло', 1500], ['рама', 12000], ['обод', 2000], ['шатун', 200], ['седло', 2700]]
```

Программа запрашивает у пользователя деталь, считает их количество, а также общую стоимость.

Пример:

```
Название детали: седло
Кол-во деталей — 3  
Общая стоимость — 4500
```
