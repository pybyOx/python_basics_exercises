## Абстрактный класс

Программа для расчёта площади различных геометрических фигур, таких как круги, прямоугольники и треугольники. 

- класс `Shape`- базовый класс для всех фигур,т хранящий пустой метод area, который наследники переопределяют;
- класс `Circle`;
- класс `Rectangle`;
- класс `Triangle`. 

Классы `Circle`, `Rectangle` и `Triangle` наследуют от класса `Shape` и реализуют метод для вычисления площади фигуры.
