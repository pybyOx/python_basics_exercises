## Имена 2

В файле `people.txt` построчно хранится N имён пользователей. 

Программа берёт количество символов в каждой строке файла и в качестве ответа выводит общую сумму. 

Если в какой-либо строке меньше трёх символов (не считая литерала \n), то вызывается ошибка и сообщение, 
в какой именно строке возникла ошибка. Программа при этом не завершается и обрабатывает все имена файла.

Все ошибки выводятся в отдельный файл `errors.log`.

**Пример работы программы**
```
Содержимое файла people.txt:
Василий
Николай
Надежда
Никита
Ян
Ольга
Евгения
Кристина

Ответ в консоли:
Ошибка: менее трёх символов в строке 5.
Общее количество символов: 49.
```
