## Отцы, матери и дети

Реализованы два класса: «Родитель» и «Ребёнок». У родителя есть:

1. Имя.
2. Возраст.
3. Список детей.

И он может:

1. Сообщить информацию о себе.
2. Успокоить ребёнка.
3. Покормить ребёнка.

У ребёнка есть:

1. Имя.
2. Возраст (должен быть меньше возраста родителя хотя бы на 16 лет).
3. Состояние спокойствия.
4. Состояние голода.
