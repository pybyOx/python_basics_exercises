## Игроки

Дан словарь игроков, которые участвовали в трёх видах спорта. В словаре хранятся пары «ФИ — очки»:

```python
players = {
    ("Ivan", "Volkin"): (10, 5, 13),
    ("Bob", "Robbin"): (7, 5, 14),
    ("Rob", "Bobbin"): (12, 8, 2)
}
```

Программа объединяет ключ словаря со значением в один кортеж и выводит результат на экран.

Результат работы программы:

```
[('Ivan', 'Volkin', 10, 5, 13), ('Bob', 'Robbin', 7, 5, 14), ('Rob', 'Bobbin', 12, 8, 2)]
```
