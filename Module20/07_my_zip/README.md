## Своя функция zip

Даны строка и кортеж из чисел. 

Программа создаёт генератор из пар кортежей «символ — число». Затем выводит на экран сам генератор и кортежи.

Пример:

```
Строка: abcd
Кортеж чисел: (10, 20, 30, 40)

Результат:
<generator object <genexpr> at 0x00000204A4234048>
('a', 10)
('b', 20)
('c', 30)
('d', 40)
```

Дополнительно: создан полный аналог функции zip — программа работает с любыми итерируемыми типами данных.
