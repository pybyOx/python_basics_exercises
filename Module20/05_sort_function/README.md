## Функция сортировки

Функция, которая сортирует по возрастанию кортеж, состоящий из целых чисел, и возвращает его отсортированным. 
Если хотя бы один элемент не является целым числом, то функция возвращает исходный кортеж.

Основной код оставлен пустым или закомментированным (используется только для тестирования).

Пример вызова функции:

```
tpl = (6, 3, -1, 8, 4, 10, -5)
print(tpl_sort(tpl))
Ответ в консоли: (-5, -1, 3, 4, 6, 8, 10)
```
